# Earl Lawrence C. Cipres — Personal Developer Portfolio

A modern, responsive developer portfolio website built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Lucide React**, crafted to faithfully recreate the visual design references.

---

## 🚀 Tech Stack

- **Framework:** React 19 with TypeScript (TSX)
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom Dark Theme matching the reference screenshots)
- **Icons:** Lucide React & Custom SVG Brand Icons
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports

## 🛠️ How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
This runs TypeScript type checking (`tsc`) followed by Vite's optimized production build.
